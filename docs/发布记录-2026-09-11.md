## 发布中捕获的问题

1. 首次发布发现 Worker Dockerfile 漏复制 `visual_guard.py`，容器启动时报 `ModuleNotFoundError`。自动回滚后在 `9e59ca8` 修复，并由生产容器验证。
2. 第二次发布的包装脚本把“FLV 长连接在 8 秒时主动超时但已收到大量数据”误触发为失败，再次自动回滚。调整为条件分支并按字节数判断后，最终发布成功。该问题不影响仓库内应用代码。

## 安全与清理

- 发布包由 Git commit 直接归档，不含 `.git`、`.env`、`node_modules`、备份或本地录像。
- Blob 公共访问被禁用，发布时只使用短时只读受保护参数。
- 发布后已删除临时 Blob 存储账户、本地/服务器临时归档和两个失败发布目录。
- 已删除 `AllowSSHTemporary`；NSG 只保留 HTTP、HTTPS 和限定为已确认场馆 `/32` 地址的 GB28181 SIP/RTP 规则。

## 已知边界

- 场馆动态公网 IP 自动白名单未合入 `main`，地址变化时仍需人工核对和更新 Azure NSG。
- 新增空画面、人体完整性和前景门控已上线，但识别精度仍必须在真实正负样本上量化，不应把规则评分解读为统计正确率。
- 当前为单馆、单机位、低并发 POC，多人跟踪、多机位和通用赛事裁判不在已验收范围。
